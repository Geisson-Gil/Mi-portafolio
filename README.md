# Portafolio 2026 — Geisson Gil

Sitio estático (HTML + CSS + JS, sin dependencias) para GitHub Pages. Rutas por `#hash`, sin configuración extra.

## Publicar
1. Sube el contenido de esta carpeta a la raíz de un repositorio.
2. Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

## Imágenes
Las de `assets/img/`, `assets/icons/` y `assets/logos/` son **recortes de tus capturas** (baja resolución). Reemplázalas por los originales de Figma **con el mismo nombre de archivo** y el diseño no cambia:
`home.jpg`, `sobre-mi.jpg`, `*-hero.jpg`, `web-*.jpg`, `foto-*.jpg`, `3d-*.jpg`, `post-*.jpg`, `ar-*`, `identidad-*`, y `logos/isotipo.png` (ideal en SVG: cambia la extensión en `index.html`, `script.js` y `style.css`).
